# 飞牛 NAS 部署清单（不自包含、不装 fnpack、crontab 每小时跑）

> 目标：在飞牛（中国大陆网络）上每小时自动测一次 Cloudflare 优选 IP，
> 推回 GitHub，让 `https://classmain.github.io/cf-speedtest-mine/` 显示大陆最优 IP。
> 全程不装 fnpack、不常驻进程、crontab 跑完就退（几乎不占内存）。

## 前提
- 飞牛能上网（大陆网络）。
- 飞牛有 `python3`（多数自带；没有就装飞牛应用中心的「Python」开发工具，非 fnpack）。
- 一个能写 `classmain/cf-speedtest-mine` 的 GitHub token（fine-grained，勾 **Contents: Read and write**）。

## 步骤（SSH 进飞牛，4 步）

### ① 把自包含脚本传到飞牛（在本机电脑上执行）
```bash
scp cf-speed-dns-mine/nas/nas_speedtest.py  用户名@飞牛IP:/tmp/
scp cf-speed-dns-mine/nas/nas_config.example.json  用户名@飞牛IP:/tmp/
```

### ② 放到家目录并写配置（SSH 在飞牛上执行）
```bash
mkdir -p ~/cf-sdtest && cd ~/cf-sdtest
cp /tmp/nas_speedtest.py ~/cf-sdtest/
cp /tmp/nas_config.example.json ~/cf-sdtest/nas_config.json
# 编辑配置，把 token 换成你的真实 token：
nano ~/cf-sdtest/nas_config.json
```
把 `"token"` 的值改成你的 `github_pat_...`，保存退出（nano：Ctrl+O 回车、Ctrl+X）。

### ③ 手动跑一次验证（约 1~3 分钟）
```bash
python3 ~/cf-sdtest/nas_speedtest.py
```
看到打印的 JSON 里 `"html": "ok HTTP 200"` / `"json": "ok HTTP 200"` 且 `top` 有 IP = 成功。
（若 `ok` 变 `unchanged(skip)` 说明数据没变，也正常。）

### ④ 加入 crontab（每小时第 5 分钟自动跑）
```bash
crontab -l 2>/dev/null | grep -v 'cf-sdtest' > /tmp/cron.new
echo "5 * * * * python3 $HOME/cf-sdtest/nas_speedtest.py >> $HOME/cf-sdtest/cron.log 2>&1" >> /tmp/cron.new
crontab /tmp/cron.new && rm /tmp/cron.new
crontab -l | grep cf-sdtest
```

## 之后
- 每小时飞牛自动测速 + 推回 GitHub → 网页自动刷新成大陆数据。
- 想看运行记录：`tail ~/cf-sdtest/cron.log`
- 改了 IP 池/间隔：编辑脚本 `IP_POOL` 或 config 的 `top_n`，保存即下轮生效。

## 排错
| 现象 | 原因 | 处理 |
|---|---|---|
| `缺少 python3` | 飞牛没装 Python | 装飞牛应用中心「Python」开发工具 |
| `HTTP 403` | token 没 Contents 写权 | 换带 Contents:RW 的 token |
| `unchanged(skip)` 一直 | 数据没变 | 正常；确认网页 `ipTop.json` 的 `version` 是否为 1.4.0 |
| 网页没更新 | GitHub Pages 在重建 | 等 1~2 分钟强刷；或查 GitHub Actions 最近 commit |

## 安全
- `nas_config.json` 里有 token，务必 `chmod 600 ~/cf-sdtest/nas_config.json`。
- token 别提交进任何 git 仓库。
